Two questions, and then the node is yours

This node works on its own. It terminates TLS, fingerprints clients, applies your rules and writes events to disk — none of which needs us, and none of which sends anything anywhere.

Two things it can do with the cloud, and only if you say so here. Both are off until you tick them, and either can be turned off again on this page at any time.

What this node may do with the cloud

{{if and .State .State.FromConfig}}

cloud.token is set in config.yaml, so the settings file decides and both directions are on. Whoever installed this node wrote it there by hand; this page does not override it.

{{else}}

Ticking either one makes the node ask the cloud for a token of the free level — nothing to copy, nobody to write to. The free level gives the crawlers that Google, Bing, Apple and Yandex publish about themselves. Network classes, carriers whose ranges must never be blocked, proxy pools and fingerprints come with a subscription.
