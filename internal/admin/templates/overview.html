Called themselves crawlers

A self-declaration is a string anyone at all can put on themselves. A claim is confirmed only when the request came from a crawler network — the ranges crawler owners publish about themselves, delivered with the fact set. The rest nobody has checked: there an impostor and a real crawler look the same.
